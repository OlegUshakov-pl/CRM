# Задача: редизайн виджета "AI Assistant" (Chat)

## Контекст
Виджет чата AI Assistant в CRM (модуль AI Assistant) визуально устарел.
Нужно переделать разметку и стили по референсу нового макета (`Chat.png`),
сохранив текущую функциональность (провайдеры, режимы CHAT/COMMANDS, отправка сообщений).

Стек: Django + Tailwind CSS 4 + Alpine.js + HTMX.

## Изменения

### 1. Карточка окна
- Углы **не** скругляем, оставляем как в старом варианте (острые).
- Добавить мягкую внешнюю тень (`shadow-lg`/`shadow-xl`).
- Увеличить внутренние отступы (padding) карточки.
- Хедер (аватар, "AI Assistant", "No provider configured", иконки delete/minimize/close) — оставить как есть, только подогнать под новые отступы.
- Шрифт по всему виджету сделать более жирным (увеличить font-weight, например с `normal`/`medium` на `semibold`/`bold` — уточнить конкретную градацию на верстке).

### 2. Поле ввода сообщения
- Заменить однострочный `input` на многострочный `textarea` (авто-расширение по контенту, с ограничением максимальной высоты и скроллом внутри).
- Плейсхолдер: `Type your message here...`
- Под плейсхолдером (когда поле пустое) показывать список подсказок буллетами:
  - `Describe what you want the AI to do in detail...`
  - `You can include context, examples, or paste documents...`
  - `Supports markdown, code blocks, files, and images`
- Подсказки скрываются, как только пользователь начинает печатать.
- Фон поля — светло-серый (`bg-gray-100`/аналог), скруглённые углы.

### 3. Тулбар внутри поля ввода (нижняя строка блока ввода)
Слева направо, слева блока:
- Иконка "скрепка" (attach file) — **с полной реализацией**: загрузка файла и прикрепление к сообщению
- Иконка "эмодзи"
- Иконка "изображение" (attach image) — **с полной реализацией**: загрузка/вставка изображения в сообщение
- Иконка `<>` (вставка блока кода)

Иконку `#` (упоминания/теги) — **не делаем**.
Микрофон (голосовой ввод) — **не делаем**.

Справа блока:
- Dropdown режима `CHAT` / `COMMANDS` (текущий функционал, просто новое расположение)
- Круглая кнопка отправки (фиолетовая, иконка стрелки), вместо текущей квадратной

### 4. Селектор провайдера
- Убрать из общего ряда с input/CHAT/send.
- Разместить отдельной строкой **под** блоком ввода, слева (`openrouter/free` + иконка шестерёнки, как сейчас).

### 5. Область сообщений
- Без функциональных изменений, только увеличить отступы в соответствии с новым padding карточки.

## Вопросы для уточнения перед реализацией
1. Загрузка файлов (`attach file`) — куда сохраняются файлы (существующее хранилище CRM / отдельный storage), какие форматы и лимит размера разрешены, передаются ли файлы в AI-провайдер как есть или только текст извлекается перед отправкой?
2. Вставка изображений (`attach image`) — изображение прикрепляется как файл (для мультимодальных провайдеров, поддерживающих image input) или просто встраивается в текст сообщения превью-ссылкой? Нужно понимать, какие из текущих провайдеров (Ollama, Anthropic, OpenAI, Google, Mistral, Groq, DeepSeek, OpenRouter, OpenCode) поддерживают image input, чтобы корректно обрабатывать не поддерживающие.
3. Иконка `<>` (вставка блока кода) — оставляем как чисто UI-хелпер (вставляет ``` в textarea) без доп. логики, верно?

## Приёмка
- Визуально совпадает с макетом `Chat.png`.
- Существующий функционал (выбор провайдера, переключение CHAT/COMMANDS, отправка сообщения) продолжает работать без регресса.
- Адаптивность виджета (сворачивание/закрытие) не сломана.
